### What this proposes

This design replaces the legacy Textual terminal interface with a local desktop GUI built in Flet (`src/fc_engineer/app.py`) for designing monospecific and bispecific antibodies (`Monospecific IgG`, `CrossMab`, `IgG-scFv`, `scFv-Fc`, `DVD-Ig`, and `BiTE`). Users can start from format templates or assemble N-to-C expressible polypeptide chains (`PolypeptideChain`) via drag-and-drop from modular domain blocks (`VH`, `VL`, `CH1`, `CL`, `Hinge`, `CH2`, `CH3`, and `G4S` linkers) and define covalent or non-covalent pairings (`InterChainPairing`) between domains. Constant domains (`CH1`, `Hinge`, `CH2`, `CH3`) are sliced from canonical WT isotype/allotype sequences and mapped to their canonical EU numbering ranges so that known mutation presets from `mutants.yaml` and file-scoped custom mutations can be routed to the appropriate domain on a chain regardless of domain order or omitted domains. Variable regions (`VH`, `VL`) and `G4S` linkers accept custom amino acid sequences and fall back to built-in Target A, Target B, and `(GGGGS)n` template sequences stored in `sequences.yaml`. Finally, the studio adds a single-file, multi-LOCUS GenBank-style `.ab` project format (with an embedded JSON manifest in the first `COMMENT` block for 2D coordinates, topology, and mutation history) alongside per-chain multi-FASTA and Pillow-rendered transparent-background `.png` 2D schematic exports.

### How the existing system works, per this document

Fc Engineering Studio is currently a Python terminal user interface (TUI) built on `Textual` (`MutantApp` and its screen flow in `src/fc_engineer/app.py`) that applies EU-numbered point mutations to a single, monolithic heavy-chain constant region sequence (`CH1-Hinge-CH2-CH3`, spanning EU 118 to 447). Reference IgG1–IgG4 isotype and allotype sequences and known Fc mutation presets are loaded from `src/fc_engineer/data/sequences.yaml` and `src/fc_engineer/data/mutants.yaml` via `src/fc_engineer/config.py`, which enforces a 1 MB file-size limit, `os.path.isfile()` checks, and `NoAliasSafeLoader` validation. Core sequence operations in `src/fc_engineer/core.py` (`get_residue_index`, `get_eu_position`, `parse_mutation`, `apply_mutations`, `diff_sequences`, `generate_batch`, `analyze_developability`) assume the sequence starts at EU 118, while `src/fc_engineer/exporters.py` provides single-sequence GenBank (`format_genbank`) and CSV (`format_csv_report`) formatting. The application also enforces a 30-second clipboard auto-clear timer and exit teardown hook to wipe copied sequences from the OS clipboard, but it has no persistent project file format, multi-chain modeling, or 2D schematic capabilities.
